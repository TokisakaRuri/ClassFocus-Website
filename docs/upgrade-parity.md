# ClassFocus 升级功能对照

本文记录旧版 Streamlit 工作台到 React/Vite 工作台的功能迁移结果。新版以 FastAPI 为唯一业务接口，推理由独立 Worker 执行，任务、报告与教师复评记录持久化到 SQLite/WAL。

| --- | --- | --- | --- |
| 课堂总览与四项指标 | React 课堂总览、实时任务/报告/复核统计 | Dashboard API + 浏览器回归 | 已迁移 |
| 当前课堂切换与刷新 | 顶栏课堂选择器、手动刷新、SSE 自动刷新 | 浏览器回归 | 已迁移并增强 |
| 跨课堂行为趋势 | 最近八堂课堂六类行为堆叠趋势 | Dashboard API + 浏览器回归 | 已迁移 |
| 证据完整度与行为解释边界 | 证据维度卡、六类行为情境解释 | 浏览器回归 | 已迁移 |
| 六类行为分布 | 数量、占比与彩色分布条 | Dashboard API + 浏览器回归 | 已迁移 |
| 分段时序与优先复核提示 | 时序证据列表、复核优先级、依据与警告 | Dashboard API + 浏览器回归 | 已迁移 |

## 回归基线

- 后端：`python -m unittest discover -s tests -v`
- 前端：`npm run build`
- 服务：`GET /api/health`、`GET /api/tasks/dashboard`、`GET /api/models/current`
- 页面：课堂总览、行为分析、任务中心、数据与模型管理；桌面和窄屏视口

视觉复核与大模型诊断会把配置范围内的课堂证据发送给所配置的大模型服务。真实浏览器回归只验证入口与状态，不主动发送课堂图像或创建额外计费请求；模型调用由隔离测试覆盖。
